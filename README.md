# StudentHub Portal

## Project Overview
StudentHub is a frontend-only academic portal designed to provide students with a single place to access courses, assignments, grades, discussions, and profile settings.

This version uses HTML5 and CSS3 only. No JavaScript, backend, or database is required for the current prototype.

## Technology Stack
- HTML5 for page structure
- CSS3 for layout, styling, colors, spacing, cards, forms, tables, and responsive behavior
- Static file-based navigation with relative links between pages

## How to Run the Project
1. Open the project folder in a browser.
2. Start from the landing page at html/index.html.
3. Use the built-in navigation links to move between pages.

> A simple local server is optional, but opening the HTML files directly in a browser will work for this static frontend.

## Page Purpose Summary
- html/index.html: Intro page with hero section, feature overview, and navigation links.
- html/login.html: Authentication interface with login and sign-up form layout.
- html/dashboard.html: Student overview screen with upcoming deadlines, course progress, and announcements.
- html/courses.html: Course catalog page showing enrolled and available courses.
- html/course_workspace.html: Course detail workspace with syllabus, materials, and module sections.
- html/assignments.html: Assignment list table with filters and status indicators.
- html/assignment-details.html: Detailed assignment page with instructions, upload area, and submission form.
- html/grades.html: Gradebook page with GPA and course-wise grade information.
- html/discussions.html: Discussion forum page with threads, categories, and forum actions.
- html/profile.html: User profile and settings page with preferences and account information.

## Design Approach
The StudentHub design is implemented as a low-fidelity frontend prototype. It uses simple boxes, borders, headings, tables, cards, forms, buttons, and navigation sections to represent the final UI structure before deeper visual enhancements are added.
