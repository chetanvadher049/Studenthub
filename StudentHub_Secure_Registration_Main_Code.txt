SECURE USER REGISTRATION USING PHP AND MYSQLI
===============================================

Aim:
Implement secure user registration by inserting user details into MySQL using
MySQLi. Validate input on the frontend and backend, check duplicate
email/username, hash passwords using password_hash(), and display appropriate
messages.

The following main code is extracted from the existing StudentHub project.

2. FRONTEND VALIDATION - javascript/register.js
------------------------------------------------

    // FORM VALIDATION
    // =====================================================

    const namePattern = /^[\p{L}\p{M}][\p{L}\p{M}\s.'’-]{1,99}$/u;
    const usernamePattern = /^[A-Za-z0-9_]{3,30}$/;
    const passwordPattern =
        /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)(?=.*[@$!%*?&]).{8,100}$/;
    const phonePattern = /^[0-9]{10}$/;

    function updateCustomValidity() {
        name.setCustomValidity(
            namePattern.test(name.value.trim())
                ? ""
                : "Enter a name between 2 and 100 characters using letters, spaces, apostrophes or hyphens."
        );
        username.setCustomValidity(
            usernamePattern.test(username.value.trim())
                ? ""
                : "Use 3 to 30 letters, numbers or underscores for your username."
        );
        email.setCustomValidity(
            email.value === "" || !email.validity.typeMismatch
                ? ""
                : "Enter a valid email address."
        );
        mobile.setCustomValidity(
            phonePattern.test(mobile.value)
                ? ""
                : "Enter exactly 10 digits for your mobile number."
        );
        gender.setCustomValidity(
            gender.value ? "" : "Choose a gender."
        );
        course.setCustomValidity(
            course.value.trim() ? "" : "Enter your course."
        );
        academicYear.setCustomValidity(
            academicYear.value.trim() ? "" : "Enter your academic year."
        );
        password.setCustomValidity(
            passwordPattern.test(password.value)
                ? ""
                : "Use 8 to 100 characters, including uppercase and lowercase letters, a number, and one of @$!%*?&."
        );
        confirmPassword.setCustomValidity(
            confirmPassword.value === password.value
                ? ""
                : "Passwords do not match."
        );
        terms.setCustomValidity(
            terms.checked ? "" : "Accept the Terms & Conditions to continue."
        );
    }

    [
        name,
        username,
        email,
        mobile,
        gender,
        course,
        academicYear,
        password,
        confirmPassword,
        terms,
    ].forEach((field) => {
        field.addEventListener("input", () => {
            updateCustomValidity();
            feedback.hidden = true;
        });
        field.addEventListener("change", () => {
            updateCustomValidity();
            feedback.hidden = true;
        });
    });


3. COMPLETE BACKEND REGISTRATION HANDLER - php/register.php
------------------------------------------------------------

<?php
require_once __DIR__ . "/auth.php";
studenthub_start_session();

try {
    if ($_SERVER["REQUEST_METHOD"] !== "POST") {
        http_response_code(405);
        header("Allow: POST");
        registrationError(
            "Invalid request",
            "Submit the registration form to create your account.",
            405
        );
    }

    if (!studenthub_verify_csrf_token($_POST["csrf_token"] ?? null)) {
        registrationError(
            "Registration form expired",
            "Reload the registration page and submit the form again.",
            403
        );
    }

    $studentName = trim(postedString("student_name"));
    $username = trim(postedString("username"));
    $email = trim(postedString("email"));
    $mobileNumber = trim(postedString("mobile_no"));
    $gender = trim(postedString("gender"));
    $course = trim(postedString("course"));
    $academicYear = trim(postedString("academic_year"));
    $password = postedString("password");
    $confirmPassword = postedString("confirm_password");
    $termsAccepted = isset($_POST["terms"]);

    if (
        !preg_match(
            "/^[\\p{L}\\p{M}][\\p{L}\\p{M}\\s.'’\\-]{1,99}$/u",
            $studentName
        )
    ) {
        registrationError(
            "Check your name",
            "Enter a name between 2 and 100 characters using letters, spaces, apostrophes or hyphens."
        );
    }

    if (!preg_match("/^[A-Za-z0-9_]{3,30}$/", $username)) {
        registrationError(
            "Check your username",
            "Use 3 to 30 letters, numbers or underscores for your username."
        );
    }

    if (!filter_var($email, FILTER_VALIDATE_EMAIL) || strlen($email) > 100) {
        registrationError(
            "Check your email",
            "Enter a valid email address of no more than 100 characters."
        );
    }

    if (!preg_match("/^[0-9]{10}$/", $mobileNumber)) {
        registrationError(
            "Check your mobile number",
            "Enter exactly 10 digits."
        );
    }

    $allowed_gender = ["Male", "Female", "Other"];

    if (!in_array($gender, $allowed_gender, true)) {
        registrationError("Choose a gender", "Select one of the available options.");
    }

    if ($course === "" || strlen($course) > 100) {
        registrationError(
            "Check your course",
            "Enter a course name of no more than 100 characters."
        );
    }

    if ($academicYear === "" || strlen($academicYear) > 30) {
        registrationError(
            "Check your academic year",
            "Enter an academic year of no more than 30 characters."
        );
    }


    if (
        strlen($password) < 8 ||
        strlen($password) > 100 ||
        !preg_match("/[a-z]/", $password) ||
        !preg_match("/[A-Z]/", $password) ||
        !preg_match("/[0-9]/", $password) ||
        !preg_match("/[@$!%*?&]/", $password)
    ) {
        registrationError(
            "Choose a stronger password",
            "Use 8 to 100 characters, including uppercase and lowercase letters, a number, and one of @$!%*?&."
        );
    }


    if ($password !== $confirmPassword) {
        registrationError(
            "Passwords do not match",
            "Enter the same password in both password fields."
        );
    }

    if (!$termsAccepted) {
        registrationError(
            "Terms required",
            "Accept the Terms & Conditions before creating your account."
        );
    }

    $conn = studenthub_db();

    $existing_account = $conn->prepare(
        "SELECT email, username
         FROM students
         WHERE email = ? OR username = ?
         LIMIT 1"
    );

    $existing_account->bind_param("ss", $email, $username);
    $existing_account->execute();
    $existing_account->store_result();

    if ($existing_account->num_rows > 0) {
        $existing_account->close();
        $conn->close();

        registrationError(
            "Account details already in use",
            "An account already uses this email address or username. Choose different details or sign in.",
            409
        );
    }

    $existing_account->close();

    $passwordHash = password_hash($password, PASSWORD_DEFAULT);

    $stmt = $conn->prepare(
        "INSERT INTO students
        (
            full_name,
            username,
            email,
            password_hash,
            phone,
            gender,
            course,
            academic_year
        )
        VALUES (?, ?, ?, ?, ?, ?, ?, ?)"
    );

    $stmt->bind_param(
        "ssssssss",
        $studentName,
        $username,
        $email,
        $passwordHash,
        $mobileNumber,
        $gender,
        $course,
        $academicYear
    );

    $stmt->execute();

    $stmt->close();
    $conn->close();

    header("Location: ../html/login.html?registered=1");
    exit;

function postedString(string $key): string
{
    $value = $_POST[$key] ?? "";

    return is_string($value) ? $value : "";
}

FEATURES SHOWN BY THIS CODE
===========================

1. Frontend validation:
   - HTML required, minlength, maxlength, pattern and input type attributes.
   - JavaScript checks name, username, email, mobile number, password,
     confirm password and terms acceptance.

2. Backend validation:
   - PHP repeats all important validation checks and does not trust the browser.
   - Validates request method and CSRF token.
   - Validates name, username, email, mobile number, gender, course,
     academic year, password strength and password confirmation.

3. Duplicate checking:
   - A prepared SELECT statement checks whether the email or username already
     exists before inserting the new account.
   - A duplicate-key database error is also handled with HTTP 409.

4. Secure password storage:
   - password_hash($password, PASSWORD_DEFAULT) stores only a password hash.
   - The original plain-text password is not inserted into the database.

5. Secure MySQLi insertion:
   - The INSERT query uses prepare() and bind_param() instead of string
     concatenation, helping prevent SQL injection.

6. Messages:
   - Successful registration redirects to login.html?registered=1.
   - Invalid input and database failures call registrationError().
   - Error titles and messages are escaped using htmlspecialchars() before
     being rendered in HTML.
