Notes:
- This project is a frontend-only static prototype.
- HTML5 and CSS3 are used for structure and design.
- There are 10 HTML pages and 10 matching CSS files.
- Each CSS file has the same base name as its corresponding HTML file.
- All CSS files are stored inside the html/css folder.
- No JavaScript files are included in the current project structure.
- No backend files or database files are included.
- The html folder contains the HTML pages and static image assets.
- The wireframe folder contains wireframe/design files.
