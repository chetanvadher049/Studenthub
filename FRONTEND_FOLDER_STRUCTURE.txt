Notes:
- HTML pages and page-specific styles are kept under html/.
- Public pages load html/css/shared.css for common branding and accessibility states.
- Dashboard and profile use PHP session checks and load the signed-in user's database record.
- Legacy dashboard.html/profile.html paths redirect to their protected PHP pages.
- Page-specific JavaScript is kept in javascript/.
- Local registration exports and student sample data are ignored to avoid publishing personal data.
- Database migrations are documented under database/migrations/.
- All pages use a consistent responsive footer with navigation and contact links.
- Shared session navigation displays Profile and Log out for authenticated students on every page.
- Public information pages have the full footer; account pages use a compact footer and generated results use a minimal footer.
- Run through a PHP-enabled server to use login, registration, profile, and contact endpoints.
- Configure php/dbconnect.php for the local database before using database-backed behavior.
- Keep all page links and asset references relative to their documented folders.
